# Currículo — Gabriel Macêdo

Aplicação de currículo desenvolvida com Vue 3 e Vite.

## Requisitos

- Node.js 22 ou superior
- npm

## Instalação

```sh
npm install
```

## Desenvolvimento

```sh
npm run dev
```

## Compilação para produção

```sh
npm run build
```

Para conferir localmente a versão compilada:

```sh
npm run preview
```

## Publicação

O GitHub Actions compila o projeto e publica a pasta `dist` no GitHub Pages a cada envio para a branch `main`.
